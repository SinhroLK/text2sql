# Legacy proof-of-concept

This directory preserves the original Llama 3.3 70B and Llama 4 Scout notebooks for historical comparison.

They are not part of the reproducible pipeline because they:

- evaluate only 50 row-split examples;
- omit database schemas and `db_id`;
- preprocess questions with stopword removal and lemmatization;
- use custom text-overlap metrics instead of the official execution evaluator;
- contain saved kernel state and API-dependent outputs.

No new production or experiment logic should be implemented in these notebooks. New notebooks belong in `notebooks/analysis/` and may only read result artifacts generated by scripts under `experiments/`.
